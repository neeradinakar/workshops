# Squared — Land, understood.

**Squared** is a land-surveyor discovery and booking concept for Telangana and Andhra Pradesh. It explores how people can move from understanding a parcel to finding a trusted surveyor, booking fieldwork, and receiving a digital report.

## Explore the portfolio

Open [`index.html`](./index.html) for the interactive portfolio. Browse the project story, filter the screen gallery by journey stage, and open any screen for a closer look or its standalone prototype.

The portfolio is a static site: no build step or package installation is needed. To preview locally, open `index.html` in a browser. The included GitHub Actions workflow deploys the site to GitHub Pages when changes are pushed to `main` (once Pages is enabled for the repository).

## The project

Squared takes on a fragmented, referral-led survey booking journey and asks what a clearer end-to-end experience might look like. The concept centers on three connected stages:

1. **Discover** surveyors and parcel context through a map-first experience.
2. **Book** with visible credentials, availability, pricing, and escrow terms.
3. **Deliver** fieldwork updates and final PDF or CAD files through one trusted flow.

### Design principles

- Make location and boundary context legible before adding complexity.
- Show surveyor credentials and payment terms clearly.
- Keep discovery, booking, and report delivery connected.
- Use a calm, trust-centered visual language with clear English and Telugu support in mind.
